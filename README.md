Entry for the make.fun competition **The Robot Vacuum's Best Excuse**
(`u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214`, $2 prize).

`main.ts` (Node 22, no dependencies) writes one line — the funniest excuse a
robot vacuum gives for missing a spot, 140 characters or fewer — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), where the
judge reads it.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/robot-vacuum-out node main.ts
cat /tmp/robot-vacuum-out/entry.txt
```
